# 项目状态机（Project Lifecycle State Machine）

schema_version: 1.0.0
stage: 跨 P0–P6
parent: 项目生命周期总规范.md

---

## 1. 目的

定义**项目级**状态（区别于章节级 FSM `core/policies/workflow.policy.yaml`）。
编排器每次接到任务先读 `lifecycle/status.yaml` 的 `lifecycle_status`，非 `ready_for_writing` 不得进入 P6 写流程。

## 2. 状态枚举（权威）

```
idea
evaluating
initiated
defining
designing
preparing_knowledge
readiness_review
ready_for_writing
writing
completed
archived
```

机器可读副本：`core/contracts/readiness-report.schema.yaml` 的 `lifecycle_status` 枚举。

## 3. 合法转移

```
idea ──批准──▶ evaluating
evaluating ──立项 pass──▶ initiated
evaluating ──否决──▶ (回 ideas/rejected)
initiated ──定义完成──▶ defining
defining ──设计源 PASS──▶ designing
designing ──Genesis 成功──▶ preparing_knowledge
preparing_knowledge ──Readiness 检查──▶ readiness_review
readiness_review ──用户批准──▶ ready_for_writing
ready_for_writing ──开始写第一章──▶ writing
writing ──全书完结──▶ completed
completed ──归档──▶ archived
```

## 4. 各阶段驱动事件

| 当前状态 | 触发条件 | 下一状态 |
|---|---|---|
| idea | 创意卡 created | idea（待评估） |
| idea | status→evaluating | evaluating |
| evaluating | INITIATION_GATE.pass | initiated |
| initiated | PROJECT_BRIEF 等 5 项齐备 | defining |
| defining | validate_sources 全 PASS | designing |
| designing | NKB-GENESIS-001 生成 | preparing_knowledge |
| preparing_knowledge | readiness 六维检查 | readiness_review |
| readiness_review | READINESS_APPROVAL.status=pass | ready_for_writing |
| ready_for_writing | 首章 plan 开始 | writing |
| writing | 末章 approved | completed |
| completed | 归档动作 | archived |

## 5. status.yaml 格式

```yaml
# <project>/lifecycle/status.yaml
lifecycle_status: designing
current_stage: P3
updated_at: 2026-07-24
updated_by: knowledge-engineer
legacy_backfill_required: false
notes: ""
```

## 6. 非法转移处理

AI 试图将状态向前跳变（如 `designing` 直接跳 `ready_for_writing`）而未持有对应 Gate 产物时：
- 角色权限层拒绝（ROLE_REGISTRY 中 `readiness-reviewer` 才写 readiness/）；
- 编排器 pre-flight 返回 BLOCKED_PROJECT_NOT_READY。

## 7. 与章节 FSM 的关系

- 本状态机管“项目能不能写”；
- `workflow.policy.yaml` 管“某一章处于 Planned→Draft→…→Published 的哪一环”；
- 两者正交：项目 `writing` 状态下，章节才允许进入 Draft。

## 8. Legacy 项目

已 writing 项目：`lifecycle_status: writing`，`legacy_backfill_required: true`。其状态机视为从 `writing` 起已合法，但须补回 P1/P2/P5 制品（见总规范 §8）。
