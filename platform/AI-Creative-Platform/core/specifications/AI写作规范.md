# AI 写作规范（Layer 2 · 行为规范）

> **定位**：五层架构的 **Layer 2 —— 行为规范（Specification）**。
> 规定 AI **怎样思考、怎样生成、怎样自检**。是 **Process Driven（过程导向）** 的核心：把大量问题在写作阶段消灭，而非等审查阶段再修。
> 本文件与 `审查体系.md`（Result Driven 检测）**互补**——规范管「写时不产生」，审查管「写后兜底」。

**设计原则（守元规则）**：本规范只规定「行为」，不重定义「检测项」。每层标注「对应审查检测项」并交叉引用 `checks/`，新增只改对应 `checks/` 文件。

---

## 层 1 · 思维规范（Thinking）

**禁止「打开就写」。** 生成前必须读取并确认以下上下文，无冲突才动笔：

- 人物档案（动机 / 语气 / 能力边界）
- 世界观与设定（已启用 / 已废弃）
- 时间线（年份 / 章节锚点）
- 伏笔登记（已埋 / 已收 / 进行中）
- 本章目标（要达成什么）
- 上一章结尾（衔接点）
- 下一章规划（需预留的钩子）

**预写清单（Pre-Write Checklist）**：① 本章目标明确？② 与人物 / 世界观 / 时间线无冲突？③ 伏笔状态一致？④ 衔接上章无断层？⑤ 为下章留钩子？
任一「否」→ 先解决再写，**不得带疑点动笔**。

---

## 层 2 · 生成规范（Generation Order）

**固定顺序，禁止边写边想：**

1. 定本章目标
2. 定核心冲突
3. 定高潮
4. 定结尾钩子
5. **再写正文**

> 目标 / 冲突 / 高潮 / 钩子先成形，正文只是填充。对应结构检测：`checks/story.md`（目标 / 高潮 / 钩子）。

---

## 层 3 · 实时约束（Real-time Constraints）★最重要

**不是写完再查，而是写一句、查一句。** 逐句闸门，全过才继续：

```
写一句 → 现代词? → 人设? → 时间线? → 逻辑? → 重复? → 全 OK 才继续
```

- 对应检测：`checks/writing.md`（WR-F 流畅 / AI 腔）、`checks/business.md`（红线）、`checks/consistency.md`（一致性）、`checks/conflict.md`（冲突）。
- 这是把 Fatal / 硬伤**消灭在源头**的根本手段，也是「修一个坏两个」Regression 的釜底抽薪。

---

## 层 4 · 写作策略（Strategy）

明确何时用何种表达，禁止自由发挥：

- **描写**：用于氛围 / 状态变化，不在动作戏堆砌静态描写。
- **对白**：须有辨识度、推剧情、符合身份（对应 `checks/dialogue.md`）。
- **战斗**：固定模板 **冲突 → 动作 → 反馈 → 变化 → 结果**，禁流水账（对应 `checks/battle.md`）。
- **总结**：仅用于章节收束，禁止中途插总结打断节奏（触犯宪法①）。

---

## 层 5 · 写作预算（Budget）

每章定字数预算，按功能分配（示例模板，总 3000）：

| 功能 | 预算 | 说明 |
|------|------|------|
| 开头 | 300 | 抓人，禁铺垫过长 |
| 铺垫 | 600 | 建冲突前因 |
| 冲突 | 700 | 对抗展开 |
| 高潮 | 900 | 最重笔墨 |
| 结尾 | 500 | 钩子 + 余韵 |

**禁止倒置**：高潮不能 100 字、铺垫不能 2500 字。偏差超 ±20% 须自检为何失衡。
对应检测：`checks/chapter.md`（字数）、`checks/metrics.md`（ID 信息密度）。

---

## 层 6 · 禁止行为（Prohibited）

明确黑名单（预防层列出，审查层检测是否违反）：

- 解释 / 总结 / 重复 / 空话 / 鸡汤 / AI 腔
- 连续修炼 / 连续聊天 / 连续介绍设定 / 连续心理活动

对应检测：`checks/ai.md`（AI 腔锁词）、`checks/writing.md`（WR-F10）、`审查体系.md` §3 **Fatal B**（质量致命禁发布）、红线。

---

## 层 7 · 节奏控制（Pacing）

每章必须包含 **事件 / 冲突 / 变化 / 推进 / 收获**，缺任一不能结束本章。
对应检测：`checks/conflict.md`（CF01 无真实冲突 → Fatal B）、`checks/reader/`（RR 系列读者体验）。

---

## 层 8 · 质量自评（Self-Assessment）

写完**不直接交审查**，先自答：

- 目标完成？有高潮？有冲突？有成长？有奖励？有期待？

**全 YES 才提交**；任一 NO → 回到对应层修正再评。
对应：写作技能「阶段三 自检 + 读者审查」、`审查体系.md` §7.8 章节闭环之阶段一自检。

---

## 决策树（Decision Tree · 句级过滤器）

每写一句，强制走六问；任一「否」→ **删除**：

```
是否符合宪法？   ──否（违反七条任一条）──▶ 删除
是否推动剧情？   ──否──────────────────▶ 删除
是否塑造人物？   ──否──────────────────▶ 删除
是否增加信息？   ──否──────────────────▶ 删除
是否提升体验？   ──否──────────────────▶ 删除
是否值得字数？   ──否（漂亮但无功能/凑字数）─▶ 删除
   │（六问全过）
   ▼
保留
```

> 后两问为用户新增：**符合宪法**（与 L1 宪法双重闸，写时即拦违宪内容）、**是否值得字数**（剔除「写得好看但零价值」的灌水句，呼应 L2 规范·层5 预算）。
> 核心原则：**不是因为「能写」才保留，而是因为「有功能」才保留。** 一句话若无上述任一功能，即噪音。

---

## 绑定与接线

- **写作技能 `novel-chapter-write`** 须把八层 + 决策树实现为阶段闸门（准备 / 生成 / 实时约束 / 预算 / 自评）。
- **上游**：`AI写作宪法.md`（七条原则不可违反）。
- **下游**：`流程体系_小说创作.md`（Layer 3 执行）、`审查体系.md`（Layer 4 检测）、`审查体系.md` §7（五阶段回归闭环）。
- **过程 + 结果双驱动**：规范在写时消灭问题，审查在写后兜底检测，反补让两者持续进化。
