## 三、如何新建一个小说项目（实例化）

```bash
# 在 workspace 根执行（自动登记进 workspace.yaml）
python platform/AI-Creative-Platform/tools/platform_cli.py init-project \
    --name 小说B --type xuanhuan --id novel-b

# 生成：projects/小说B/（project.yaml + 空 NKB + overrides + metrics + artifacts + memory/project）
# 然后：
python platform/AI-Creative-Platform/tools/platform_cli.py bootstrap   # 兼容性检查 → 生成缓存
```

脚手架已自动完成：选模板、建 `project.yaml`（锁 Plugin 版本）、从 Schema 生成空 NKB、建 `overrides/` `metrics/` `artifacts/` `memory/project/`、登记进 `workspace.yaml`。随后 `bootstrap` 校验全 PASS 即可进入写作。

**关键**：新项目只持有自己的事实（NKB）与运行结果（artifacts/metrics/memory/project），**绝不复制全局 Core 与类型模板**。
