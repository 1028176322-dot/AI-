# 权重 Profile 机制

## 作用
本目录权重仅作用于**支柱一 · 专业编辑审查（质量）**的 ES 编辑综合分。模块权重**不写死**在主文档。不同小说类型重要度完全不同（恋爱文情感重、战斗为 0；科幻世界观重），通过切换 Profile 改变加权，正文与检查项库**无需改动**。

> 注意：支柱二 AI 工程审查（CI/AI 错误密度）与支柱三 读者审查（Reader Index/PI）**不使用本目录权重**，各自独立评分，由支柱四发布门禁综合。

## 规则
1. 每个 Profile 的 **13 模块**权重之和**必须＝100%**（v4.2 起：原 10 模块 + ⑪叙事审查 + ⑫对白审查 + ⑬冲突审查）。
2. 不适用模块权重可置 0，但须把权重**重新分配**给其他模块（不允许「丢失权重」）。
3. 审查启动时声明类型 → 加载对应 Profile → 加权算 ES（支柱一）。
4. 未声明类型 → 默认加载 `default.md`（玄幻基准）。
5. 新增类型：复制 `default.md` 改名，改权重，校验和为 100，提交即可，**不动主文档**。

## 权重字段（13 模块）

> 新增 3 个 craft 模块（⑪⑫⑬）权重默认 叙事6 / 对白4 / 冲突4，各 Profile 统一；如需按类型微调（如恋爱文对白加重），在该 Profile 内调整并校验和=100。
