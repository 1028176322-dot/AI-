   - 章纲与章节地图、卷纲、剧情弧必须完整连续覆盖；
   - 每章必须声明叙事策略、开头设计、结尾设计和完整前后 Plan 链。

2. 新增 `writing-strategy@1.0.0`：

   - 领取章节任务时自动生成 `STRATEGY-CH-NNN.yaml`。

3. 开头与结尾由章纲驱动：
   - 开头必须承接上一章实际结果，并适配首场景；
   - 结尾必须兑现本章变化、记录不可逆变化并桥接下一章；
   - 决定、发现、关系变化、代价、兑现、余韵、威胁、新目标等均可形成留存动力，不再强制所有章节使用截断悬念。

4. 新增跨章反模板门禁：
   - 连续三章不得使用相同开头或结尾模式；
   - 与最近十章的正文开头/结尾边界相似度不得超过 0.75；
   - 禁止仅换人物、意象或形容词来伪装相同叙事骨架。

5. 写作与审查闭环：
